# Calculator Project
A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This project is designed to practice front-end web development and JavaScript fundamentals.

# How to Run
1. Clone this repository:

   ```bash
   git clone https://github.com/diljanb259-lab/calculator-project.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
